# 말랑 펫 — 멍때리기용 미니 펫 게임

작성: [Claude] · 2026-10-26 · 리소스: [Codex] `desktop_pet_assets_v2/` (기준)

작은 창 속 방에서 동물이 혼자 생활하는 걸 구경하는 게임이다. 가끔 쓰다듬거나 장난감으로 놀아 줄 수 있다.
동물은 **고양이·강아지·병아리·곰·토끼 5종**(메뉴의 동물 버튼으로 순환, 버튼에 지금 동물 표시). 병아리·토끼는 시트에 그려진 대로 작다.
**친구 버튼으로 둘이 모드**: 둘째 동물이 들어와 같이 산다 — 알아서 다가가 비비고(하트), 같이 뛰어놀고, 가끔 티격태격한다(마주 보고 화냄 → 덮치기 → 한쪽이 데굴 구르고 도망, 만화식 — 아픈 연출 없음). 짜증나 있을수록 다툴 확률이 높다.
시트는 리소스 README 지침대로 **선택한 동물 것만** 읽는다(혼자 20장, 전환·친구 추가 때 그 동물 것을 그때 읽음). 고른 동물·친구는 저장돼 다음에 켜도 유지.
**효과음**: 녹음 파일 없이 WebAudio 로 합성한 동물별 소리(고양이 야옹조, 강아지 멍, 병아리 삐약, 곰 낮은 소리, 토끼 찍). 평소(자율 행동)엔 조용하고 **만지거나 놀아줄 때만** 난다 — 클릭·들기·떨어뜨리기·배 만지기·간지럼·간식·낚싯대 덮치기 등. 메뉴의 소리 버튼으로 끌 수 있다.
숙제·재화·벌점은 없고, 방치해도 아프거나 죽지 않는다. 배고픔·졸림·심심함·친밀감은 다음 행동을 고르는 데에만 쓴다.

## 켜기

- **`MiniPet.bat`** 더블클릭 → 크롬 앱 창(주소창 없음, 560×380)으로 뜬다.
  창 크기·위치는 페이지가 기억한다. 크롬이 없으면 엣지로 연다.
  게임 전용 브라우저 프로필은 `%LOCALAPPDATA%\MiniPet\browser`(평소 크롬과 분리, 확장·동기화 끔)에 둔다.
- 폴더를 옮기면 `powershell -ExecutionPolicy Bypass -File tools\make_shortcut.ps1` 로 바로가기를 다시 만든다.
- 그냥 `index.html` 을 브라우저로 열어도 된다(서버 필요 없음). 이때는 창 크기만 기억하지 않는다.
- **모바일**(크롬·삼성 인터넷, 가로·세로): 웹 주소(https://leepillwoo.github.io/malang/)로 열면 된다. 터치로 똑같이 논다(문지르기·꾹 누르기·위로 끌기). 세로 화면에서는 방을 크게 보여 주고 카메라가 동물을 따라 좌우로 움직인다.

## 조작

| 하는 것 | 어떻게 |
| --- | --- |
| 쓰다듬기 | 고양이 위를 누른 채 문지르기. 계속하면 부비기 → (친해졌으면) 배 보여주기 → 배를 계속 만지면 간지럼 |
| 클릭 | 고양이를 짧게 누르기. 자꾸 귀찮게 하면 놀라고 → 화내고 → 피해서 삐진다 |
| 집어 들기 | 고양이를 꾹 누르기(0.35초) 또는 위로 끌기(대각선 포함). 흔들면 몸이 말랑하게 흔들리고, 높이서 놓으면 데굴 굴렀다 일어난다. **가구 자리에 놓으면 그 위에 앉는다**(상자·숨숨집은 안으로) |
| 유리 톡톡 | 빈 곳 누르기. 고양이가 쳐다보고, 앞쪽이면 다가와 맞받아 톡톡하거나 화면 유리에 찐빵처럼 붙는다 |
| 공 | 공을 끌어서 던지기 / 짧게 눌러 톡 / 막대의 공 버튼 = 방에 던져 주기 |
| 낚싯대 | 막대의 깃털 버튼 → 마우스로 깃털 흔들기. 시선이 따라오고 살금살금·폴짝·덮치기. Esc 나 우클릭으로 내려놓기 |
| 물고기 인형·줄 장난감 | 버튼으로 꺼내기/치우기. 줄은 고양이가 물고 있을 때 반대쪽 끝을 끌면 줄다리기 |
| 간식 | 간식 버튼 → 손에 든 채 움직이면 따라와 조른다 → 아무 데나 누르면 떨어뜨림 → 냄새 → 먹기 → 만족 |
| 낮·밤 | 해/달 버튼: 자동(시계, 21~7시 밤) → 낮 고정 → 밤 고정 |
| 친구 | 친구 버튼: 없음 → 고양이 → … → 토끼 → 없음 순환. 친구도 똑같이 쓰다듬고 들고 놀아 줄 수 있다 |
| 소리 | 소리 버튼으로 켬/끔 (기본 켬, 인터랙션 때만 남) |

메뉴는 **오른쪽 위 발바닥 버튼**을 눌러야 열린다(마우스만 움직여선 안 떠서 화면을 가리지 않음). 빈 곳 클릭·Esc·버튼 재클릭으로 닫힌다. **창 높이에 맞춰 1~3열로 접혀** 작은 창에서도 잘리지 않는다(460px 미만 2열, 270px 미만 3열). 오랜만에 켜면(45분 이상) 앞으로 달려와 반긴다.

## 고양이의 하루 (자율 행동)

다음 장면을 욕구·시간·최근에 한 것을 보고 고른다. 같은 장면은 연달아 잘 안 나오고, 장면마다 쉬는 시간이 있다.
입력 없이 6시간을 빨리 감았을 때 시간 비율: 가만히(숨쉬기·깜빡·두리번) 39% · 잠 31% · 산책 11% · 그루밍 3% · 상자/숨숨집/공/관심 요청/우다다 등 나머지.

| 장면 | 흐름 |
| --- | --- |
| 가만히 | 숨쉬기 · 눈 깜빡 · 마우스가 움직이면 두리번거리며 눈으로 따라감(오래 올려 두면 부끄러워함) |
| 산책 | 두리번 → 걷기(가끔 달리기) → 앉기 → 세수 |
| 낮잠 | 침대·쿠션·숨숨집으로 폴짝 → 앉기 → 세수 → 하품 → 눕기 → 잠(밤엔 길게) → 깨기 → 기지개 · 가끔 인형 안고 졸기 |
| 혼자 놀기 | 꼬리 잡기 → 뒹굴기 → 아무 일 없던 듯 대기 / 발 장난 → 덮치기 / 무언가 발견 → 살금살금 → 덮치기 |
| 우다다 | 갑자기 놀람 → 방 끝까지 왕복 질주 → 앉아서 세수 |
| 관심 요청 | (한동안 안 놀아 주면) 심심해 → 놀아줘 → 반응 있으면 기뻐함, 없으면 삐지고 혼자 놀기 · 화면 유리 톡톡 · 찐빵 |
| 창문 찐빵 | 앞으로 와서 유리에 붙기 → 눌린 채 유지 → 미끄러짐 → 떨어지기 → 몸 털기 |
| 상자·숨숨집 | 폴짝 들어가 웅크리기 → 빼꼼 |
| 둘이(친구 모드) | 다가가 마주 보고 부비기(하트) · 놀자고 한 뒤 쫓고 쫓기기 · 티격태격(화냄 → 덮치기 → 데굴 → 도망 → 둘 다 뾰로통) |
| 밥 | 배고프면 밥그릇으로 → 냄새 → 먹기 → 만족 |

56개 행동이 모두 장면이나 반응에서 쓰인다(무작위 입력 6시간 점검에서 56/56).

## 구조 — 동물 추가

- 동물은 `w.pets` 배열(1~2마리)이고 장면·이동·물리가 전부 공용이다. 둘이 장면은 한쪽이 이끌고(social) 상대를 끌어들이는(social_follow) 짝 구조 — 단계 공유 객체(duet)로 맞추고, 중간에 사용자가 끼어들면 그대로 끝난다.
- 게임 코드는 **행동 ID 만** 안다. 동물 이름·파일 경로·좌표는 코드에 없다(경로는 manifest, 숫자는 config·tuning).
- 동물 추가: Codex 가 `desktop_pet_assets_v2/characters/<동물>/` 에 14장 + manifest 등록 → `node tools/prepare.cjs` → 끝.
  56행동 × 6프레임이 다 있는 동물만 "준비됨"이 되고, 둘 이상이면 막대에 동물 바꾸기 버튼이 생긴다.
  실제로 10-26 저녁 Codex 가 강아지·병아리·곰·토끼를 추가했고, 게임 쪽 작업은 `prepare.cjs` 재실행 + `pet.size`(시트 속 상대 크기) + 점프 공중 프레임 기준점(`tuning.js`, 측정값) 세 가지였다.
  공·인형 안는 자리(`hug`)는 자동 측정 기본값으로 시작하고, 어색한 동물만 `tuning.js` 에 맞춘다(지금은 고양이만 수동).
- 리소스 폴더를 바꾸면(`config.js assetBase`) `prepare.cjs` 를 다시 돌린다. v1/v2 manifest 형식 차이는 `prepare.cjs` 가 흡수한다.
  가구 그림은 폴더마다 다르므로(v1 터널 ↔ v2 숨숨집) 배치는 `config.js sets.<폴더 이름>` 에 따로 둔다.

## 리소스 연결에서 처리한 것

- **기준점**: v2 는 manifest 기준점(128, 220)을 그대로 쓴다(공중 높이가 칸 안에 그려져 있음). 점프 공중 3프레임만 게임이 포물선으로 띄우므로 그림 속 높이를 뺐다(`tuning.js`). v1 은 칸 중심 고정 기준점이라 몸이 최대 37px 흔들려, 알파로 잰 접지점을 쓴다.
- **머리 꼭대기·입·앞발·클릭 마스크**는 `prepare.cjs` 가 알파로 측정한다. 들기는 머리 꼭대기(목덜미)를 잡고, 클릭은 그림 모양(24×24 마스크)으로 판정한다(투명 여백을 눌러도 안 잡힘).
- **소품은 독립 오브젝트**: 공은 굴러가며 회전·튐·가구 충돌, 밀기 프레임(2번)에 앞발이 닿을 때 힘을 받는다. 안기 프레임에서만 앞발 사이에 붙는다. 인형·줄은 입 위치에 붙고, 줄은 양 끝 매듭 기준으로 늘어지거나 팽팽해진다.
- **가림**: 상자·숨숨집 = 뒤 그림 → 고양이 → 앞 파츠 순서. 숨숨집 안은 입구 밖이 클릭되지 않고 안쪽 그늘을 어둡게 칠한다. 침대는 같은 그림의 앞 테두리를 고양이 위에 다시 그린다.
- **가구 뒤 깊이(10-26 저녁 사용자 피드백)**: 들어서 놓은 자리가 가구 발밑이면 바닥 대신 **그 가구 위로 내려앉는다**(화면상 발 위치는 이어짐). 추격·우다다로 지나가다 가구 발밑에 서게 되면 앞쪽으로 걸어 나온다(이동 중에는 끼어들지 않음 — 목표와 싸우면 교착). 간식도 가구 발밑에 떨어지면 앞으로 굴러 나온다.
- **침대 깊이(10-27 피드백)**: 침대 앞 테두리를 동물 위에 다시 덮던 방식을 뺐다 — 누운 몸이 중간에서 잘려 "뒤로 들어간" 것처럼 보였다. 쿠션처럼 동물을 통째로 위에 그린다(자연스러움은 화면으로 확인).
- **말풍선(수면 zzz·감정)**: 기본 크기를 키우고 동물 몸 크기에 비례해 더 키운다(`headFx`, 몸 폭/165 배, 1.25~2.2배).
- **둘이 모드**: 겹쳐 서면 살짝 밀어 벌리고(서 있는 쪽만), 유리 찐빵은 한 마리씩만, 공·인형·줄은 안은 동물 기준으로 그린다.
- **모바일(10-27)**: 캔버스 크기를 CSS `100vh` 가 아니라 `innerWidth/innerHeight` 로 직접 준다(모바일 `100vh` 는 주소창이 숨었을 때 높이라 삼성 인터넷 등에서 그림이 늘어나고 아래가 가려졌다). 회전 직후 크기를 늦게 알려 주는 브라우저가 있어 150·400·900ms 에 다시 잰다. **세로로 긴 창**은 방 그림이 창 높이의 `tallFill`(72%)은 채우게 키우고(최소 `minVisibleW` 폭은 보임) 카메라가 동물을 따라간다 — 화면 가운데 40~60% 를 벗어나면 부드럽게, 30~70% 밖으로는 못 나가게. 이때 시뮬의 `view` 는 방 가로 전체(동물은 방 어디든 다님)이고 화면 폭은 `view.w` 로 따로 준다(유리 찐빵 크기). 손가락을 대고 있는 동안은 카메라를 멈춘다(손 아래 그림이 미끄러지지 않게). 터치 길게 누르기도 `contextmenu` 를 내므로 낚싯대·간식 내려놓기는 마우스 우클릭일 때만.
- **창 크기**: 방 가로 전체가 보이게 맞추고, 넓은 창에선 위(벽)만 잘린다. 고양이·공·들고 있는 고양이·유리 찐빵 크기는 창 안에 들게 제한한다. 다닐 수 있는 깊이도 머리가 안 잘리는 만큼으로 줄어든다.
- **CPU — 3단계 그리기(10-27 최적화 점검)**: 위치가 움직일 때만 화면 주사율, 말풍선·안긴 소품처럼 잔잔한 것만 있으면 초당 20번, 아무것도 없으면 다음 애니메이션 프레임 "직후"까지 쉰다(직전에 깨면 같은 그림을 두 번 그리던 버그 수정). 창을 내리거나 가리면 완전히 멈춘다. 효과음 컨텍스트도 15초 조용하면 재운다.
  실측(640×420): 깨어 가만히 9.4회/초 · 잠(zzz) 15.5회/초(이전 30) · 둘이 가만히 8.8회/초 · 놀 때만 60회/초. 그리기 1회 0.05ms(밤 필터 0.13ms — 무시 수준). 시뮬 1틱 0.005ms.
- **이동 교착 방지**: 목표가 화면 가장자리 보정(fitX)과 싸워 제자리걸음이 되면 0.4초 뒤 그 지점을 도착으로 친다(다툼 뒤 맨 앞줄로 도망갈 때 영원히 못 끝나던 버그의 근본 수정).

## 남은 것 · 한계

- **프레임 보간은 하지 않는다(10-26 저녁 피드백에 대한 답).** 행동이 6프레임 손그림이라 중간 자세가 존재하지 않고, 두 프레임을 겹쳐 섞으면(크로스페이드) 잔상 두 겹으로 보여 더 나쁘다. 대신 **이동·공 궤적은 화면 주사율로** 그려 움직임 자체는 부드럽다. 동작 프레임이 더 촘촘하길 원하면 아트 쪽(행동당 8~12프레임)이 필요하다 — `ART_SPEC.md` 선택 항목.
- **사람 손으로 직접 놀아 본 건 아직이다.** 위 점검은 자동 입력이다. 걸음 속도·잠 길이·관심 요청 빈도 같은 "느낌"은 써 보면서 `config.js` 숫자로 맞추면 된다.
- `shy`(부끄러워하기)는 마우스를 고양이 위에 2.5초 이상 가만히 올려 두면 나온다. 무작위 점검에선 이 조건을 안 만들어서 "입력 없이" 실행에선 안 쓰인다.
- **효과음은 합성음이다.** 실제 녹음 울음소리가 아니라 WebAudio 파형으로 만든 "게임풍" 소리라, 귀로 듣고 톤이 마음에 안 들면 `js/audio.js` 의 `VOICE`(동물별 음높이·파형) 숫자로 조절한다. 헤드리스 점검은 "울림 호출이 나는지"까지만 — **실제 소리 느낌은 사용자 확인 필요.**
- 둘이 모드의 관계는 기분(annoy·affection)만 쓴다 — 누적되는 우정 수치 같은 건 없다(원하면 추가).
